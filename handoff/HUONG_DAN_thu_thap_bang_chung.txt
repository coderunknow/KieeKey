GÓI NÀY LÀ GÌ
-------------
- kieekey_ui_probe.exe: chương trình ĐO (không phải bản vá). Nó mở đúng cửa
  sổ Cài đặt thật (cùng class, cùng code layout, cùng code scroll như
  KieeKeyApp.exe bản beta8fix2 — đúng code đang chạy trên máy bạn), chạy toàn
  bộ bộ kiểm tra mà phòng đo đã chạy 7 vòng: đúng scale 150% thật, đúng font
  thật, đủ 9 tab, kéo thumb thanh cuộn THẬT, và audit pixel trên màn hình
  thật. Nó KHÔNG cài hook bàn phím, KHÔNG tạo tray, KHÔNG sửa settings, và
  chạy được CÙNG LÚC với KieeKeyApp.exe đang chạy (không đụng mutex). Nó tự
  khai báo môi trường trong báo cáo: "host: win 10.0.19044 ... native dpi 144".
- collect_report.ps1 + run_probe_and_report.bat: thu thập MÔI TRƯỜNG TRƯỚC
  (OS build, LogPixels, DWM/theme, GPU + driver, số tiến trình + File version
  + SHA-256 của MỖI KieeKeyApp.exe, tasklist, cửa sổ nào phủ vùng dialog),
  SAU đó chạy probe, rồi zip tất cả thành 1 file.
- kieekey_ui_probe.pdb: symbol file — nếu probe rơi crash, giúp đọc crash log.
  Không chạy nó.
- BUOC_CHAY_PROBE_chi_tiet.txt: hướng dẫn từng bước (BẮT BUỘC đọc trước).

CÁCH CHẠY (khoảng 3–5 phút probe + 2 phút chuẩn bị)
----------------------------------------------------
Xem BUOC_CHAY_PROBE_chi_tiet.txt — tóm tắt:
1. 4 file (exe, pdb, ps1, bat) vào CÙNG MỘT thư mục (vd: kk-probe).
2. Đóng cửa sổ Cài đặt của app (bỏ app chạy trong tray).
3. Chụp S1: toàn bộ cửa sổ Cài đặt KỂ CẢ THANH TIÊU ĐỀ.
4. Đúp run_probe_and_report.bat → chờ 3–5 phút, ĐỪNG CHẠM cửa sổ.
5. Gửi file kieekey-report-<thời-gian>.zip + S1 + S2 (tab Cấp độ) + S3
   (khi bắt được chữ nhân bản, nếu có).

CLEAN BOOT (H2 — làm sau probe, ~15 phút; chi tiết ở file bước-chi-tiet 14–19)
-------------------------------------------------------------------------------
Win+R → msconfig → Services → tick "Hide all Microsoft services" → Disable
all → Startup → Open Task Manager → disable tất cả → restart → test S1–S3 →
chụp → GHI RÕ "clean boot: hết lỗi / lỗi vẫn còn" → bật lại (Normal startup).
