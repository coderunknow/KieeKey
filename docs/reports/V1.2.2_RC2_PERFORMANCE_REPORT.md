## 1. What changed vs RC1

### 1.1 Engine (`src/core/TextEngine.*`) — decision-frozen except where broken

| Change | Class | Hot-path cost |
|---|---|---|
| `replacementUtf16`: VIQR map gated on `codeTable == Unicode` | render-only, one predictable branch | ≈0 (see floor) |
| `resetForConfigurationChange()` (new API; full session reset) | setup path only | 0 (never called per key) |
| `startNewSession()` | UNCHANGED (deliberate — commit paths read fields back after it) | 0 |

### 1.2 App wiring (`src/app/main.cpp`, `src/ui/MainWindow.xaml.cpp`)

All five Win32 reconfigure sites and all three WinUI ones now call
`setOptions(...) + resetForConfigurationChange()`. The WinUI code-table combo
previously changed the table with NO session reset at all; the perf-strategy
`useDictionaryRestore` flip intentionally keeps its no-reset mid-word semantics
(documented: renders from next key, decisions from next word).

### 1.3 Reference oracle (`tests/vi_oracle.hpp`) — the harness had bugs too

quick-telex syllable-initial guard (v1.2.0 engine semantics were not modelled);
quick-END re-emission now spans `newCharCount` (the rewritten pair), matching the
engine and every canonical consumer. Both had masked real engine behaviour in
lockstep runs that only the new matrix depths exposed.

## 2. Throughput floor (RC2 series)

Driver: `tests/bench_tput_floor.cpp` (committed; RC1's was ad-hoc — this closes
that gap). 20 M-key deterministic mixed stream, mode 1 = `process()` +
`replacementUtf16()` into a reused scratch, sink digest guards run-equality.

All numbers below from `tests/bench_tput_floor.cpp` — the floor driver is versioned
in-repo from RC2 onward (RC1's was an ad-hoc script whose 43.07 ns/key absolute cannot
be re-measured and was never directly comparable: different keystream). Driver default
`--keys=20000000 --iters=3 --mode=1` (mode 1 = `process()` + `replacementUtf16()` into
a reused scratch; the sink folds decisions AND render bytes so digest drift is
impossible).

| Measure | Value |
|---|---|
| Paired A/B, quiet host, 5 runs/side | RC1 med **71.58**, RC2 med **72.07** ns/key; mean paired Δ **+0.13 %** (noise band) |
| Sinks | **identical on all 10 runs** — `2905520108639366859` |
| RC2 floor (published, median of 3) | **71.43 ns/key**, same sink |

The +0.13 % delta is expected: the RC2 render path gains one predictable branch
(`codeTable == Unicode` in the non-VIQR leg), the setup-path additions cannot show
here. The A/B is the authoritative no-regression evidence; the 71.43 median is the
bar future releases inherit.
