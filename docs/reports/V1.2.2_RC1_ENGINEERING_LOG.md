## 1. Scope freeze

Second-generation **engine hot-path** work only.

In scope: `src/core/TextEngine.hpp`, `src/core/TextEngine.cpp`.
Out of scope (on purpose): hook, TSF composer, `win32_wrapper` pipeline,
PerfProfile defaults, notifications, UI, Windows-only lifecycle.

Standing constraints carried from v1.2.1:

* Do not sacrifice Telex / VNI / Unicode / hook / TSF / lifecycle correctness.
* Dual-emitter `emitMtx` stays unless a measured, proven alternative exists.
* Evidence-driven: measure → optimize → prove. No fabricated benches.
* Frozen methodology vs v1.2.1 Stable on **this** host. Do not compare this
  g++ 12.2 54.41 ns/key against the RC3 report's g++ 14.2 40.2 ns/key as if
  they were the same experiment.

## 3. Candidate-1 (the KEEP set)

One candidate. No second-guessing after the A/B landed.

### 3.1 Sequence buckets (`TextEngine.cpp` anonymous namespace)

`SeqIdxBucket` / `MarkSeqBucket`, built at constexpr time from the last
cell of each sequence under `seqMask` ∈ {0, `kEndConsonantMask`}.

* `kDSeqBuckets{Off,On}` — `kConsonantD`
* `kMarkSeqBuckets{Off,On}` — flattened `kVowelForMark` (group A→Y, then
  sequences), preserving the `for (auto& e : kVowelForMark)` visit order
  that carries the upstream master tone-mark fix
* `kVowel{A,E,O,W}{Off,On}` — `kVowel` entries 0..3

`static_assert` on bucket width 48 (namespace-scope lambda, same pattern
as RC3's consonant buckets — **not** an in-class assert on a private
member).

`handleMainKey` D / mark / vowel scans iterate the bucket for
`lastChr`, keep the `index_ < seq.size()` continue, then call
`checkCorrectVowel` exactly as before.

### 3.2 Classifiers (`TextEngine.hpp`)

* `isWordBreakChar`: `lo` bits 33–47 (`!`..`/`) and 58–63 (`:`..`?`);
  `hi` bits for `@ \ ^ _ \`` `{`..`~`. `[` and `]` are **not** in the
  set (Telex standalone ơ/ư). Non-ASCII → false.
* `isVowelChar`: `0x01104111u` bits 0,4,8,14,20,24 = A E I O U Y.
* `isMarkKey` Telex: `0x00860220u` = S F R J X.

An in-class `static_assert` calling those `static constexpr` members was
tried and **reverted**: GCC 12 (and the same rule on MSVC) rejects
"called in a constant expression before its definition is complete".
That would have broken GitHub `/WX`. The bitmasks stay; the illegal
asserts do not.

### 3.3 `checkSpelling` length-1 exit

After the leading-consonant match, if `spellingEndIndex_ == 1`: a lone
vowel is OK, a lone unmatched consonant is already classified, QU/GI and
vowel-combine cannot run. Set `tempDisableKey_` and return.

### 3.4 `vowelCombineFor`

Switch on A/E/I/O/U/Y → `&kVowelCombine.entries[i].second`. Used from
`checkSpelling(forceCheckVowel)` and `canHasEndConsonant`.

## 6. Things that were looked at and left alone

### 6.1 `emitMtx` (dual emitter) — KEEP

The Windows consumer can emit through TSF *or* inline `SendInput`. The
hook thread has a ring-full fallback that also `SendInput`s. `SendInput`
is atomic per call, not across calls; two interleaved streams produce
garbled Unicode. `InlineEmitter` serializes on `emitMtx`. That lock is
not on the Linux engine driver. Removing it would be a product-correctness
change with no engine-ns payoff. **KEEP.**

### 6.2 Pipeline, hook, TSF, lifecycle

v1.2.1 Stable just closed a TSF use-after-free, two cross-thread handle
reads, and the pending-counter underflow. This RC does not reopen that
surface.

### 6.3 `isSpecialKey` Telex OR-chain

Still an OR of W E R O [ ] A S D F J Z X W (W duplicated, inherited).
Converting it is noise next to `handleMainKey`. Left.

### 6.4 Vowel-combine *matching* (the inner tone-bit walk)

RC3 rejected this. Still rejected. Sequential, semantic, leftover
single-digit ns.

### 6.5 Product flags (`-O3`, `-march=native`, profile defaults)

RC2 rejected. No new evidence.

## 8. Dead ends (do not retry)

* **In-class `static_assert` of a `static constexpr` member** — GCC 12:
  "called in a constant expression before its definition is complete".
  Would fail MSVC `/WX` the same way. Removed.
* **Linking `tput_driver.cpp` without `TextEngine.cpp`** — the driver
  does not pull the TU in; undefined refs. Always compile both.
* **Comparing this host's 54 ns/key to RC3's 40.2** — different compiler
  (12.2 vs 14.2). Relative Δ on this host is the only honest number.
* **Claiming E2E reduction from engine-only ns/key** — shim p50 is a
  ~10 µs timer floor here. Not re-run, not claimed.
